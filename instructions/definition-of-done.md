# Definition of done

For each future feature, explicitly consider:

- implementation and boundary placement;
- request and domain validation;
- authentication, authorization, and ownership;
- API contract and structured errors;
- unit, integration, end-to-end, concurrency, and regression tests as applicable;
- database schema and reviewed migration requirements;
- concurrency, transaction, idempotency, and performance implications when relevant;
- logging, observability, privacy, and audit implications;
- OpenAPI documentation;
- changelog and engineering documentation; and
- successful formatting, lint, type-check, test, and build checks.

A non-applicable item may be documented as such. A required failing check prevents an unqualified completion claim.
